# Articles Directory

Place your article HTML files in this directory.

## Naming Convention

- French articles: `ArticleName_(French_Version).html`
- English articles: `ArticleName_(English_Version).html`

## Example

```
Califrais_(French_Version).html
Post_Baobab_(English_Version).html
```

## To Add Articles

1. Copy your HTML files from the original `articles` directory to this `public/articles` directory
2. The articles will be automatically accessible at `/articles/[article-name]`
